# Power BI Dashboard

## Dashboard Overview

The Power BI dashboard presents an interactive view of electronics manufacturing quality performance.

## KPI Cards

The dashboard contains:

* Total Units Produced
* Defective Units
* Defect Rate
* Average Inspection Score
* Total Downtime

## Visualizations

### Quality Overview

* Defect Rate by Production Line
* Defect Rate by Component Type
* Monthly Defect Trend

### Defect Analysis

* Defect Type Distribution
* Defect Rate by Shift
* Temperature vs Defect Status
* Humidity vs Defect Status
* Inspection Score vs Defect Status
* Downtime Analysis

## Filters

The dashboard provides filters for:

* Production Date
* Production Line
* Component Type
* Shift
* Defect Type

## Data Source

The dashboard uses the cleaned manufacturing dataset generated and processed through the Python workflow.

The Power BI `.pbix` file can be added to this folder after completing the dashboard in Power BI Desktop.
