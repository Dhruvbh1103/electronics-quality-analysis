# Electronics Manufacturing Quality Analysis & Defect Prediction

## Project Overview

This project analyzes electronics manufacturing quality data to identify defect patterns, evaluate production quality, and predict whether a manufactured unit is likely to be defective.

The project combines **Python, SQL, Machine Learning, and Power BI** to demonstrate an end-to-end data analytics workflow.

## Business Problem

Manufacturing organizations need to continuously monitor product quality and identify factors that may be associated with defective products.

This project aims to analyze manufacturing data and answer the following questions:

* What is the overall defect rate?
* Which production lines have higher defect rates?
* Which component types have more defects?
* What types of defects occur most frequently?
* How do manufacturing conditions relate to product defects?
* How does quality vary across production shifts?
* Can machine learning predict whether a manufactured unit will be defective?

## Objectives

1. Clean and prepare manufacturing quality data.
2. Perform exploratory data analysis using Python.
3. Analyze manufacturing quality using SQL.
4. Identify patterns associated with product defects.
5. Build a machine-learning model for defect prediction.
6. Evaluate the prediction model using appropriate classification metrics.
7. Create an interactive Power BI dashboard.
8. Generate business insights from the analysis.
